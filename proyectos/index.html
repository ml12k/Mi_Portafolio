Sobre nosotros

ML12K Web es un proyecto de desarrollo web enfocado en crear sitios modernos y funcionales para pequeños negocios. Nuestro objetivo es ayudar a los negocios a tener una presencia profesional en internet mediante páginas web adaptadas a sus necesidades.

Proyectos realizados

💈 Barbería Istmo

Proyecto demostrativo de ML12K Web para una barbería con diseño elegante, lista de servicios, galería, ubicación y botón de reserva por WhatsApp.
